# Exercise 4: Creating and Configuring a Maven Project

## Objective

Create and configure a Maven project for a Spring application.

## Implementation

- Created a Maven project named `LibraryManagement4`.
- Configured the project using `pom.xml`.
- Added the Spring Context dependency.
- Added the Spring AOP dependency.
- Added the Spring Web MVC dependency.
- Configured the Maven Compiler Plugin.
- Set the Java source and target versions to Java 1.8.
- Verified the project configuration using Maven.

## Build Command

    mvn clean compile

## Result

The Maven project was configured successfully and completed with `BUILD SUCCESS`.
