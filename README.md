Week 5 - ReactJS Hands-on Exercises
Overview
This folder contains the mandatory ReactJS hands-on exercises completed as part of the Cognizant Deep Skilling Java Full Stack Engineer (Java FSE) program.
The exercises cover the fundamentals of React development, including components, JSX, props, state, lifecycle methods, event handling, conditional rendering, CSS Modules, ES6 features, and rendering lists using the `map()` function.

How to Run Any Exercise
Navigate to the exercise folder.
```bash
cd Exercise-X
```
Install dependencies.
```bash
npm install
```
Start the development server.
```bash
npm start
```
Open your browser.
```text
http://localhost:3000
```
