# 📘 Week 6 – Git Hands-On Labs (Git-HOL)

## 📌 Overview

This repository contains the **Week 6 Git Hands-On Lab (Git-HOL)** exercises completed as part of the **Cognizant Digital Nurture 4.0 Program**. The exercises focus on mastering Git fundamentals, repository management, branching strategies, merge conflict resolution, and collaboration with remote repositories.

Throughout these labs, practical experience was gained in configuring Git, tracking files, managing branches, resolving merge conflicts, using `.gitignore`, and synchronizing local repositories with remote repositories using Git.

---

## 🎯 Learning Objectives

- Configure Git on a local machine.
- Manage Git user configuration and default editor.
- Initialize and manage Git repositories.
- Track and commit files using Git.
- Work with remote repositories.
- Ignore unnecessary files using `.gitignore`.
- Create and manage branches.
- Merge branches and analyze Git history.
- Resolve merge conflicts using Git and P4Merge.
- Synchronize local and remote repositories using pull and push operations.

---

## 📂 Hands-On Exercises

### ✅ Exercise 1 – Git Configuration & Repository Setup
- Configured Git username and email.
- Verified Git installation and configuration.
- Integrated Notepad++ as the default Git editor.
- Initialized a local Git repository.
- Created and tracked project files.
- Added files to the staging area.
- Created commits with meaningful messages.
- Connected the local repository with a remote repository.
- Performed pull and push operations.

---

### ✅ Exercise 2 – Working with `.gitignore`
- Created and configured a `.gitignore` file.
- Ignored unnecessary log files (`*.log`).
- Ignored log directories.
- Verified ignored files using `git status`.
- Maintained a clean working directory.

---

### ✅ Exercise 3 – Branching & Merging
- Created and switched between branches.
- Added and committed changes on feature branches.
- Compared branch differences.
- Used P4Merge for visual comparison.
- Merged feature branches into the main branch.
- Verified merge history using Git logs.
- Deleted merged branches.

---

### ✅ Exercise 4 – Merge Conflict Resolution
- Simulated merge conflicts between branches.
- Compared conflicting changes.
- Used Git Diff and P4Merge for conflict analysis.
- Performed three-way merge conflict resolution.
- Updated `.gitignore` to exclude backup files.
- Completed merge conflict resolution with proper commits.
- Cleaned up merged branches.

---

### ✅ Exercise 5 – Remote Repository Synchronization
- Verified repository status.
- Pulled latest changes from the remote repository.
- Pushed pending local commits.
- Confirmed successful synchronization between local and remote repositories.
