# Exercise 3: Assertions in JUnit

## Objective

Demonstrate the use of common JUnit 5 assertion methods to validate expected outcomes during unit testing.

## Assertions Used

* `assertEquals()` – Verifies that the expected and actual values are equal.
* `assertTrue()` – Checks whether a condition evaluates to true.
* `assertFalse()` – Checks whether a condition evaluates to false.
* `assertNull()` – Verifies that an object reference is null.
* `assertNotNull()` – Verifies that an object reference is not null.
