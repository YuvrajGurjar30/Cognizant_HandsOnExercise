# Exercise 3 - React Functional Components

## Objective

Create a React application named **scorecalculatorapp** to understand functional components, props, and component styling.

## Technologies Used

- React
- JavaScript (ES6)
- JSX
- CSS
- Node.js
- npm
- Visual Studio Code

## Project Structure

```
scorecalculatorapp
│
├── src
│   ├── Components
│   │   └── CalculateScore.js
│   │
│   ├── Stylesheets
│   │   └── mystyle.css
│   │
│   ├── App.js
│   └── index.js
│
├── package.json
└── README.md
```

## Features

- Functional React Component
- Passing data using Props
- Calculating student score percentage
- Custom CSS styling
- Reusable component design

## Props Used

- Name
- School
- Total
- Goal

## Formula

```
Score = Total / Goal
```

The score is displayed as a percentage with two decimal places.

## Expected Output

```
Student Details

Name : Steve
School : DNV Public School
Total : 284 Marks
Score : 94.67%
```

## How to Run

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```

Open:

```
http://localhost:3000
```
