# Exercise 13 - Lists, Keys and Conditional Rendering

## Objective

Develop a React application named **bloggerapp** to understand Lists, Keys, the `map()` function, and Conditional Rendering.

## Technologies Used

- React
- JavaScript (ES6)
- JSX
- CSS
- Node.js
- npm

## Concepts Covered

- Lists in React
- Keys
- map() Function
- Conditional Rendering
- Functional Components
- Props

## Components

- BookDetails
- BlogDetails
- CourseDetails

## Features

- Displays book details using `map()`
- Displays blog details using `map()`
- Displays course details using `map()`
- Uses unique keys for each list item
- Demonstrates conditional rendering for each component

## How to Run

```bash
npm install
npm start
```

Open:

```
http://localhost:3000
```

## Learning Outcome

After completing this exercise, you will understand:

- Rendering lists in React
- Using keys with lists
- Passing data through props
- Conditional rendering
- Component-based UI design
